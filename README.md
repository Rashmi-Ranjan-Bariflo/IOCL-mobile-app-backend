# IOCL Mobile App Backend

Backend API for the IOCL Mobile Application.

This project provides the backend services, REST APIs, authentication,
database management, and business logic required for the IOCL Mobile App.

## Project Information

- **Project:** IOCL Mobile App
- **Backend:** Django
- **API Framework:** Django REST Framework
- **Database:** PostgreSQL
- **Authentication:** JWT
- **Language:** Python
- **Environment:** Python Virtual Environment
